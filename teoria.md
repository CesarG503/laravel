

## Artisan 
    
    Es la interfaz de línea de comandos (CLI) integrada en el framework PHP Laravel, utilizada para automatizar tareas comunes de desarrollo, como la creación de código, la gestión de bases de datos y el inicio de un servidor web local. 

## composer

    Es un gestor de dependencias para PHP que automatiza la instalación, actualización y gestión de bibliotecas externas en un proyecto.
